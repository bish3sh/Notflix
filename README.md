# NOTFLIX: Web-based media streaming platform
**NotFlix** is a Netflix-inspired web application designed to deliver an engaging and seamless entertainment streaming experience.

Developed using standard web technologies including HTML, CSS, JavaScript, and PHP, NotFlix features a dynamic interface for browsing movies and TV shows, responsive media playback, and content management.

## Technologies
  - **Frontend**: HTML5, CSS3, JavaScript[cite: 2]
  - **Backend**: PHP[cite: 2]
  - **Database**: MySQL

## Objectives

- To Provide a Wide Range of Digital Media Content
- To Build an Intuitive, Netflix-Inspired Interface
- To Ensure Smooth Content Navigation and Playback

## Features
- Dynamic Movie & Series Catalog
- Interactive Video Player
- Content Search and Category Filtering
- Responsive Design for Mobile and Desktop
